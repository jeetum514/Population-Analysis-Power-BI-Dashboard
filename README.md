# 🌍 Population Analysis Dashboard

## 📌 Project Overview

The **Population Analysis Dashboard** is an interactive Power BI dashboard that provides insights into population trends across different countries and regions. It enables users to analyze population distribution, growth patterns, and demographic statistics through dynamic visualizations.

## 🎯 Objectives

* Analyze population distribution by country/region.
* Compare population growth across years.
* Identify countries with the highest and lowest populations.
* Visualize demographic trends using interactive charts.

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX (Data Analysis Expressions)**
* **CSV** (Data Source)

## 📊 Dashboard Features

* Total Population KPI
* Population by Country
* Population by Continent/Region
* Year-wise Population Trend
* Top 5 Most Populated Countries
* Interactive Filters (Slicers)

## 📈 Key Insights

* Identifies regions with the highest population concentration.
* Highlights population growth trends over time.
* Compares demographic statistics across countries.
* Enables interactive exploration through slicers and filters.
